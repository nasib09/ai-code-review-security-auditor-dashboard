# AI Code Review & Security Auditor Dashboard

A browser-based dashboard for auditing software repositories for security issues and code quality concerns using AI-driven analysis.

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run start`

## Overview

This project is a working frontend prototype for a security auditor dashboard inspired by the provided product specification. It includes:

- repository-style file tree
- code view and risk overlays
- audit findings panel
- severity taxonomy and fix suggestions
- API route stubs for future AI integration

## Roadmap
